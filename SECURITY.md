# Security and sensitive reports

This alpha can send conversation excerpts to an external evaluator and run the local Claude/curl executables. Read [privacy](docs/privacy.md) before using it on private work. Best-effort masking is not a data-loss-prevention system.

Do not put secrets or real transcripts in public issues. If you suspect credential exposure, revoke the affected credential through its provider and keep reproductions synthetic. Use GitHub's private vulnerability reporting if it is enabled for this repository; do not include secrets in public reports.

Only the currently tested alpha is evaluated. No independent security audit has been completed.
