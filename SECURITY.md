# Security and sensitive reports

This alpha can send conversation excerpts to an external evaluator and run the local Claude/curl executables. Read [privacy](docs/privacy.md) before using it on private work. Best-effort masking is not a data-loss-prevention system.

Do not put secrets or real transcripts in public issues. If you suspect credential exposure, revoke the affected credential through its provider and keep reproductions synthetic. The published repository's private vulnerability reporting channel will be used when available; this unpublished candidate does not invent a contact address or promise a configured reporting channel.

Only the currently tested alpha is evaluated. No independent security audit has been completed.
