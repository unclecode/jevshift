# Synthetic examples

`jev-request.json` is the complete JSON body generated by the current collector and evaluator prompt from an invented retry-helper conversation. It contains `questions.model_choice` (Sonnet, Opus or Fable), `questions.effort_choice` (low, medium, high, xhigh or max), and a Markdown/XML `state`. At runtime the state also lists discovered capabilities and fixed controls; pinned dimensions are omitted from the questions. It is an inspectable request example, not a recorded provider response or accuracy assertion. It has no authentication header and makes no call by itself.

`local-environment.settings.json` explicitly permits an already-inherited OpenRouter key, with auto disabled. `local-auto.settings.json` additionally permits the isolated auto command. Both use the local `jevshift` identity; installed marketplace configuration uses `jevshift@jevshift`. See [configuration](../docs/configuration.md). Do not add a real credential to these files.
